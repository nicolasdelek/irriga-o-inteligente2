Conexão com o ESP32

Sobre o projeto

A irrigação manual em pequenas estufas costuma depender da disponibilidade e da memória de quem cuida das plantas — o que leva a solos encharcados, plantas ressecadas e desperdício de água.

A proposta

Este projeto automatiza a irrigação com um ESP32 que lê continuamente um sensor de umidade do solo e decide, dentro de limites configuráveis, quando ligar e desligar uma bomba d'água de 12 V através de um módulo relé.

Como funciona

O ESP32 conecta-se à rede Wi-Fi local e disponibiliza uma API HTTP própria. A interface web consulta essa API periodicamente e envia comandos de controle, sem depender de nenhum servidor externo.

Benefícios

  • Economia de água, evitando irrigação além do necessário
  • Praticidade: liga e desliga a bomba automaticamente
  • Monitoramento remoto pelo celular ou computador
  • Histórico do que aconteceu enquanto ninguém estava por perto
